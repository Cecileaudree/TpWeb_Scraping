# Usage IA

## Outils utilisés

- OpenAI / ChatGPT (GitHub Copilot) pour :
  - structurer le projet
  - proposer la séparation des responsabilités
  - générer des exemples de code Python lisibles

## Rôle de l'IA

L'IA a aidé à créer un squelette de collecteur et à écrire les modules de base, mais le contenu métier, l'organisation de projet et les choix d'architecture restent explicitement validés ici.
